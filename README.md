
## Features

- JWT Authentication (Register / Login / Logout)
- Users with roles (Admin / User)
- Countries → Destinations → Tours / Hotels / Attractions
- Protected APIs using Bearer Token
- Database seeding with realistic travel data

---

## Tech Stack

- Laravel (Latest)
- PHP 8+
- MySQL
- JWT Auth 

---

## Setup Instructions

## 1️. Clone Repository

git clone https://github.com/Vaishnavi213460/Backend-Eurasia-Travel.git
cd backend-eurasia-travel

## 2. Install dependencies

    composer install

## 3. env setup
  
    update database and credentials in .env file

## 4. Run migrations 

    php artisan migrate

## 4. Database seed

    php artisan db:seed

## 5. Start Development Server

    php artisan serve

## Use the Base url to run apis - http://127.0.0.1:8000
